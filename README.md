A single 1024x1024 editorial poster summing up Thursday 19 November 2026.

The top panel covers the first ever US–China–Russia trilateral summit in
Shenzhen, where Donald Trump, Xi Jinping and Vladimir Putin signed a
"Declaration Towards Peace" and said the three countries are "uniquely
positioned" to discuss cutting nuclear arsenals. The lower panel covers the
International Court of Justice ruling that Myanmar committed genocide against
the Rohingya, with refugees watching from the Cox's Bazar camps.

The poster is drawn deterministically with Pillow — no randomness, no clocks,
no network — so every run produces byte-identical output. `main.py` is a
standard-library-only entry point that copies the committed PNG to
`/output/entry.png`.

## Run it

```sh
python3 main.py
```

Regenerate the artwork (requires Pillow):

```sh
python3 make_image.py
```
